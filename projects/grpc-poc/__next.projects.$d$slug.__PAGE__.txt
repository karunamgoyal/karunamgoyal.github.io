3:T578,<p><h2>Overview</h2></p>
<p>A proof-of-concept demonstrating how to run a gRPC service behind an Envoy proxy that translates HTTP/JSON requests to gRPC — enabling REST clients to communicate with gRPC backends without any client-side gRPC library.</p>
<p>Built during my Flipkart internship while working on REST POJO to proto3 IDL conversion tooling. Distributed at Flipkart scale, service mesh patterns like this are critical — this POC was my first deep dive into them.</p>
<h2>Architecture</h2>
<pre><code>REST Client → Envoy (HTTP/JSON to gRPC transcoding) → Java gRPC Service
</code></pre>
<p>Envoy is configured with <code>grpc-http1.1-bridge</code> and <code>grpc-json-transcoder</code> filters. The proto descriptor is compiled and passed to Envoy at startup so it knows how to map REST endpoints to RPC methods.</p>
