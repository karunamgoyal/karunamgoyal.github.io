Flipkart UPI

Senior contributor on Flipkart UPI — scaled from zero to 10 million users in 6 months. Built the core microservices stack powering 10M customers at high scale.

JavaDropwizardApache KafkaDistributed SystemsUPIFintech

Overview

Part of the core Flipkart UPI senior team — contributed from the founding phase through product maturity. Achieved 1 million customers in week 1 and 10 million users within 6 months of launch.

What I Built

  • User Service — identity and profile management for UPI users
  • Gateway — entry point for all UPI traffic, request routing and auth
  • UI Adaptation Layer — server-driven UI contracts for the UPI frontend
  • Rewards Manager — UPI rewards and cashback engine
  • Notification Module — transactional notifications for UPI events
  • Auto-pay — recurring payment mandate management
  • Rate-limiter Module — per-user and per-partner rate limiting
  • Timeout Module — UPI transaction timeout handling and reconciliation

Distributed Streaming Platform

Implemented a high-performance distributed platform using Apache Storm with Apache Kafka and Apache Pulsar as stream sources. Supported 8 critical async use-cases including the UPI live transaction flow — ensuring scalability and fault tolerance at 10M-user scale.

Tech

Java, Dropwizard, Apache Kafka, Apache Storm, Apache Pulsar, Kubernetes, high-throughput microservices.
